httpx2-negotiate-sspi
=====================

HTTP Negotiate authentication for ``httpx2`` using Windows SSPI.

This package supports Kerberos and NTLM authentication, including TLS channel
binding tokens for services that enforce Extended Protection for
Authentication.

The documentation is organized into onboarding, usage guidance, API reference,
troubleshooting, and contributor notes.
